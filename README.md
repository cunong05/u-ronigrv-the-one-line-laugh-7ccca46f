# The One-Line Laugh — "My AI agent asked for a raise..."

One original English one-liner about an AI agent asking for a raise:

> My AI agent asked for a raise, so I gave it a bigger context window and called it a corner office with a view of my inbox.

## Why this line?

It treats the agent like an office employee — a raise, a corner office, a view — then swaps the perks for the only currency an AI actually values: a bigger context window. The punchline is the "view of my inbox", the one window no agent ever asked for but every agent ends up staring at. One sentence, one joke, no setup wasted.

## How it works

`main.ts` (Node 22, stdlib only, no network) writes exactly one line — 122 characters, no trailing newline — to `/output/entry.txt`, after a gate that the line is 80–140 characters and contains no newline.

## Run it

```sh
node main.ts
```

Then check the entry:

```sh
cat /output/entry.txt   # My AI agent asked for a raise, so I gave it a bigger context window and called it a corner office with a view of my inbox.
```
